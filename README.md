# Python Programming Exercises Collection

This repository is a collection of Python programming exercises and small practice projects designed to build programming skills through hands-on coding.

## Contents

- Basic Python exercises
- Small beginner-friendly projects
- Input/output practice
- Loops, conditionals, and logic building
- Simple menu and receipt programs

## Example project

- `ordring_system/` contains a snack and drink ordering system exercise.

## How to run

Navigate to the project folder and run a Python file, for example:

```bash
python ordring_system/question_1.py
```

## Purpose

The goal of this repository is to practice Python fundamentals, improve problem-solving, and create simple but useful mini-projects.
